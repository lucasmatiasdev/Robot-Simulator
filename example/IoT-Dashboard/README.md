# Dashboard IoT

## Introducción

El proyecto consiste un un dashboard IoT para las Clases de Cloud robotic en donde los alumnos podran suscribirse a varios componentes y usarlos en sus aplicaciones IoT.

Para instalar todas las dependencias:
```
npm install .
```
Para ejecutar el proyecto completo:
```
npm run start
```
Para ejecutar el proyecto completo en modo desarrollador:
```
npm run dev
```
Para ejecutar solamente el servidor del proyecto:
```
npm run server
```
Para ejecutar solamente el servidor del proyecto en modo desarrollador:
```
npm run server-dev
```
